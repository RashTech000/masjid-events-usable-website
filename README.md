# 🕌 Masjid Kisota Website

A modern and responsive website for **Masjid Kisota**, designed to provide the mosque community with useful Islamic information, announcements, prayer times, and important updates.

## 🌙 About the Project

The Masjid Kisota Website is a community-focused web project created to provide an easy and accessible online platform for the mosque.

The website is designed with a clean Islamic-inspired interface and responsive layout so that it can be accessed from both mobile phones and computers.

## ✨ Features

* 🕌 Masjid Kisota homepage
* 🕋 Islamic-inspired modern design
* 🕐 Prayer times
* 📢 Mosque announcements
* 🖼️ Image slideshow / mosque gallery
* 📱 Responsive design for mobile and desktop
* 🌙 Islamic information
* 📍 Mosque location information
* ⚙️ Admin functionality
* 🔄 Dynamic content updates
* 🎨 Modern visual design

## ⚙️ Configuration

Website configuration can be managed through the project configuration files.

Example:

```json
{
    "mosque_name": "MASJID KISOTA",
    "city": "Dar es Salaam",
    "country": "Tanzania"
}
```
